# Live Sentence Boundary Source Caches

This directory contains historical/source live-window caches.

Use `data/datasets/elevenlabs_scribe_27` as the canonical consolidated 27-video dataset root. That normalized dataset copies the relevant files from these source caches and from `D:\Projekte\WhoSpeaks`, groups them by canonical YouTube ID, and records coverage in `manifest.json` and `coverage.csv`.

The folders here are kept for provenance and rebuilds:

- `live_window_corpus_60_90_cuda_complete_23`: 23 live-window caches with all 15 provider embeddings.
- `live_window_corpus_60_90_cuda_missing_1x`: source 1x live-window runs for the requested videos.
- `live_window_corpus_60_90_cuda_more_4`: the remaining four live-window caches copied from WhoSpeaks, now with all 15 provider embeddings generated by the remote Linux embeddings server.

Do not use the `complete_23` folder name as the answer to 27-video dataset coverage. The canonical dataset has live sentence/audio caches and live-window provider embeddings for all 27 videos.
