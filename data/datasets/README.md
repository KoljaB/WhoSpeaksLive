# Datasets

Canonical local datasets live here.

- `elevenlabs_scribe_27`: normalized 27-video ElevenLabs Scribe baseline corpus with one folder per canonical YouTube ID, baseline transcripts, baseline embeddings, live-window sentence/audio caches, live-window embeddings where available, and coverage manifests.
- `_build_elevenlabs_scribe_27.py`: rebuilds `elevenlabs_scribe_27` from the historical source folders in this repo and `D:\Projekte\WhoSpeaks`.
