# Bundled language flags

These 4:3 SVG country flags come from [flag-icons](https://github.com/lipis/flag-icons)
and are redistributed under its MIT license in `LICENSE`.

WhoSpeaks maps each supported language to one representative country flag in
`window.language_config.LANGUAGE_FLAG_COUNTRY_CODES`. The displayed language
name is authoritative because many languages are used in more than one country.
